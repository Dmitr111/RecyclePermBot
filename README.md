# RecycleBot

Recycle Perm Bot — Telegram-бот, который ищет пункты приёма отходов в Перми. Это моя курсовая работа с первого курса. Проект учебный, бот сейчас не развёрнут и не работает, репозиторий оставлен как пример кода.

## Что умеет бот

- Пользователь выбирает тип отходов: пищевые отходы, стеклотара, металлолом, пластик, батарейки и аккумуляторы, текстиль или макулатура.
- Бот находит через API поиска по организациям Яндекса до 10 подходящих пунктов приёма в Перми. В ответ приходит карта с метками (Yandex Static API) и список с адресами и телефонами.
- Если отправить геопозицию или координаты текстом (`58.0105, 56.2502`), бот строит маршрут до ближайшего пункта и присылает ссылку на Яндекс Карты.
- К каждому типу отходов есть короткий совет. Советы можно отключить в профиле.
- В профиле (`/data`) видно, сколько раз пользователь искал пункты по каждому типу, сколько у него баллов и какое место среди остальных пользователей.
- Если человек не писал боту 5 дней, бот присылает ему напоминание.
- Администратор может разослать сообщение всем пользователям: для этого нужно отправить текст вида `$текст$`.

Команды: `/start`, `/help`, `/data`, `/sorting`.

## Стек

- C#, .NET 8, консольное приложение
- [Telegram.Bot](https://github.com/TelegramBots/Telegram.Bot) 18 (long polling)
- Newtonsoft.Json
- Yandex Static API и API поиска по организациям Яндекса
- [DotNetEnv](https://github.com/tonerdo/dotnet-env) для загрузки `.env`
- MSTest для тестов класса `TelegramUser`

Базы данных нет: пользователи хранятся в файле `users.json` (chat ID, выбранный тип отходов, счётчики запросов, время последнего сообщения). В этом файле данные пользователей, поэтому он добавлен в `.gitignore`.

## Настройка

Токен и ключи задаются через переменные окружения. Их можно прописать в системе или положить в файл `.env` в корне репозитория, рядом с `RecycleBot.sln`.

Бот ищет `.env` в текущей рабочей папке, а если там его нет, поднимается вверх по дереву каталогов. Поэтому файл в корне находится и при запуске из корня, и из `src/RecycleBot`, и из Visual Studio (там рабочая папка `src/RecycleBot/bin/Debug/net8.0`). Переменные, уже заданные в окружении, важнее значений из `.env`.

| Переменная | Обязательна | Что это |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | токен бота от [@BotFather](https://t.me/BotFather) |
| `YANDEX_STATIC_API_KEY` | да | ключ Yandex Static API |
| `YANDEX_SEARCH_API_KEY` | да | ключ API поиска по организациям |
| `ADMIN_CHAT_ID` | нет | chat ID администратора; без него рассылка отключена |

Ключи Яндекса выдаются в [кабинете разработчика](https://developer.tech.yandex.ru/).

```sh
cp .env.example .env
# затем впишите свои значения в .env
```

Если обязательная переменная не задана, бот сразу завершится и напишет, каких значений не хватает.

## Запуск

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

Все команды выполняются из корня репозитория:

```sh
dotnet build
dotnet run --project src/RecycleBot
```

Бот остановится, если нажать `Q` в консоли.

`users.json` создаётся в текущей рабочей папке, а не рядом с проектом. При запуске командой выше это корень репозитория, при запуске из Visual Studio — `src/RecycleBot/bin/Debug/net8.0`. Если запускать бота из разных мест, у каждого будет свой список пользователей.

Тесты:

```sh
dotnet test
```
